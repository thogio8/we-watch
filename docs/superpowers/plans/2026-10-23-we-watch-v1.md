# we-watch V1 — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** une appli web mobile first pour deux, qui permet de swiper ou rechercher des films (TMDB) pour remplir une liste « à voir », puis de tirer au hasard le film du soir avec son heure de fin.

**Architecture :** Next.js App Router. Les pages serveur lisent la base, les composants client gèrent les interactions et les Server Actions écrivent. La logique métier pure (transitions de statut, tirage, heure de fin) vit dans `src/domain/` sans aucune dépendance au framework. La persistance passe par un repository Drizzle et TMDB par un client typé (zod) : ce sont les deux seuls points de contact avec l'extérieur. Le code est rangé par fonctionnalité (`src/features/{draw,swipe,list}`), et les primitives visuelles de la DA sont dans `src/ui/`.

**Tech Stack :** Next.js (dernière version stable, App Router, TypeScript strict), npm, Drizzle ORM + drizzle-kit, `@libsql/client` (Turso en prod, fichier SQLite en local), zod, `motion` (geste de swipe et animations), CSS Modules + custom properties, Vitest + Testing Library (jsdom), ESLint + Prettier.

**Spec :** `docs/superpowers/specs/2026-10-23-we-watch-design.md`. Maquette : `docs/superpowers/specs/assets/2026-10-23-we-watch-mockup.html`. Les deux se lisent avec ce plan.

## Review Focus

1. **Film sans durée** (`runtime` à `null` ou `0` chez TMDB) : le tirage affiche « DURÉE INCONNUE », jamais « FINI À NaNHNaN ». Test : Task 2.
2. **Heure de fin après minuit** : 23h30 + 125 min doit donner « 01H35 », pas « 25H35 ». Test : Task 2.
3. **Page TMDB entièrement déjà décidée, ou fin du catalogue** : le deck enchaîne sur la page suivante sans afficher de carte vide. À la dernière page, il affiche l'écran de fin. Test : Task 7.
4. **Double décision sur le même film** (double tap, ou deux téléphones) : la première décision du swipe l'emporte, la seconde est un no-op silencieux. Test : Task 5.
5. **TMDB indisponible ou token invalide** : une erreur typée `TmdbError` est levée et l'écran affiche un message dans la DA. Ni écran blanc ni stack trace. Test : Task 6 (client) et Task 10 (UI du swipe).

- Produces :

  ```ts
  /** roll ∈ [0, 1) ; choisit floor(roll * eligibles.length) parmi les candidats hors exclus, dans l'ordre reçu. */
  export function pickMovieId(candidateIds: readonly number[], excluded: ReadonlySet<number>, roll: number): number | null;

  export type DrawPhase = "home" | "result" | "exhausted" | "empty";
  export interface DrawSessionState { phase: DrawPhase; currentId: number | null; pile: readonly number[] }
  export const initialDrawSession: DrawSessionState; // { phase: "home", currentId: null, pile: [] }
  export type DrawSessionAction =
    | { type: "draw"; candidateIds: readonly number[]; roll: number }
    | { type: "reject"; candidateIds: readonly number[]; roll: number }      // current → pile, puis retire
    | { type: "reset_pile"; candidateIds: readonly number[]; roll: number }  // vide la pile, puis retire
    | { type: "watched" }                                                    // vide pile + current, phase home
    | { type: "back_home" };
  export function drawSessionReducer(state: DrawSessionState, action: DrawSessionAction): DrawSessionState;
  ```
